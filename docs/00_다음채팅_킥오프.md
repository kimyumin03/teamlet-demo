- 외부 의존성 = 인터페이스 추상화

- `IEmployeeDirectory.bulkSync()` — 수기 CSV와 AxHub API가 동일 시그니처

### 벌크 처리 인프라 ⭐⭐ (중요)
- **MVP**: 수기 단건 입력 + CSV 일괄 업로드 (HR이 직접)
- **AxHub 연동 후**: 동일 인프라 위에서 API bulk sync (자동)
- 모든 벌크 작업 = `BulkOperation` + `BulkOperationRow` 통과 (직접 createMany 금지)
- Employee에 `data_source` / `axhub_external_id` / `sync_locked_fields` 필드
- AxHub가 관리하는 필드는 UI에서 수기 편집 차단
- 화면: `/members/bulk-import` + `/members/bulk-import/[operationId]`
- 처리 파이프라인: 입력 → 파싱·검증 → 미리보기·충돌해결 → 확정 → 24h 롤백
