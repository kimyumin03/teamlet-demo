> **목표**: 클로드로 뽑은 리뉴얼 디자인을 실제 앱(`apps/web`)에 페이지 단위로 1:1 정합.
> **원칙**: 비주얼 = 디자인 기준 / 데이터·서버액션·권한 = 실제 유지 (양방향 reconcile). **채용(recruit) 제외.**
> 최종 업데이트: 2026-06-05 (**디자인 단계 1차 완료** — 7개 영역 정합/검증 끝)

## 0. 디자인 정답 소스 (중요)

```

├── app/*.jsx           ← ★ 디자인 프로토타입 (React+Babel). 페이지 구조의 정답
```

## 1. 작업 방식 (페이지마다 4단계, 차근차근 검증)

1. **우리 설계 확인** — `docs/06_화면_명세서.md` (+ `docs/05_디자인_시스템.md`) 해당 페이지 스펙
2. **Flex 비교** — `docs/02_Flex_분석_종합.md` / `docs/08_휴가_Flex갭분석.md`
3. **새 디자인 대조** — 위 `app/*.jsx` + `styles/*.css` ↔ 실제 페이지 1:1
4. **반영 + 검증** — 비주얼=디자인·기능=실제로 수정 → `cd apps/web && npx tsc --noEmit` → `curl -L localhost:3001/<route>` (200 + 컴파일 에러 無) → 보고

## 2. 환경

- dev 서버: **localhost:3001** 상시 구동 중 (`pnpm dev`, turbopack). docker(postgres/redis/minio) healthy.
- 검증: `cd apps/web && npx tsc --noEmit` (exit 0 확인) + `curl -s -o /dev/null -w "%{http_code}" -L http://localhost:3001/<route>`
- 인증 필요 라우트는 미로그인 시 /login 리다이렉트(200)지만 **라우트 모듈은 컴파일됨** → CSS/JSX 에러 검출 가능.
