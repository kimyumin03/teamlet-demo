# 09. 휴가 도메인 — Flex 완전 분석 & 통합 설계

> 작성일: 2026-06-01 (Opus 설계)
> 근거: Flex 캡처 3폴더 전수 분석 — `flex`(347장, 전 영역) + `flexv2`(97장, 휴가 심층) + `teamlet`(37장, 휴가관리 관리자뷰) + 연차촉진 웨비나 PDF
> 목적: 휴가 도메인의 **모든 기능·화면·모달·선택지·연계**를 Flex 수준으로 정의. 디자인은 Claude 기본 디자인, 기능·문구·선택지는 Flex 동일.
> ⚠️ 이 문서가 휴가 구현의 단일 기준(SSOT). [[08_휴가_Flex갭분석]] 보완.

## 0. 도메인 기능 맵 (휴가가 가진 모든 기능)

```
휴가 도메인
├── [설정] 연차 설정          (settings=annual-time-off)
│   ├── 연차 정책 (복수 생성)
│   │   ├── 승인·참조자 + 승인 요청 시점(등록할때/취소할때)
│   │   ├── 연차 사용 단위 (시간/반차/일)
│   │   ├── 당겨쓰기 설정 (자유/사용량 제한 N일)
│   │   ├── 연차 부여 방식 (회계일/입사일 + 월차·만근·소수점 규칙)
│   │   ├── 자동 소멸 설정 (월차/연차 분리 + 유예기간)
│   │   └── 스마트 연차 촉진 (연차/월차 1·2차 시점)
│   ├── 퇴직자 연차 조정 기준
│   └── 연차 촉진 설정 (리마인드·알림시점·촉진시점)
├── [설정] 맞춤 휴가          (settings=custom-time-off)
│   └── 휴가 종류 (법정 필수 + 회사 자율)
│       ├── 부여 방법/단위/시간/사용단위/급여
│       ├── 승인·참조자 (휴가별 고정) ★
│       └── 추가 설정 (성별/증명/제외대상/휴일차감)
├── [구성원] 내 휴가          (my-time-off)
│   ├── 휴가 개요 (휴가 등록 카드 → 신청 모달)
│   ├── 연차 상세 (월별 원장)
│   └── 연차 사용 계획 (촉진 응답)
├── [관리자] 휴가 관리        (time-tracking/time-off)
│   ├── 휴가 보유 현황 (+맞춤휴가부여/연차조정)
│   ├── 휴가 사용 내역
│   ├── 월별 연차 사용 내역 (+엑셀 업로드)
│   └── 연차 촉진 (촉진 진행/관리)
├── [연계] 워크플로우         (FormDocument 결재)
├── [연계] 알림              (승인요청/완료/촉진/리마인드)
└── [연계] 승인 정책 관리     (휴가별 결재선 = 맞춤휴가/연차정책에서 설정)
```

## 1. 휴가 종류 마스터 (Flex 18~19종)

법정 필수(`isRequired`) + 회사 자율. Flex `맞춤 휴가` 목록 + `휴가 보유 현황` 컬럼 기준:

| 휴가명 | 분류 | Flex 부여 방식 | 기본 승인/참조 |
|---|---|---|---|
| 가족돌봄 | 필수 | 신청 시 1일 부여(무급) | 승인 없음 |
| 군소집훈련 | 필수 | 신청 시 부여 | 1단계+참조1 |
| 난임 치료 | 필수 | 매년 6일 부여 | 1단계+참조1 |
| 배우자출산 | 필수 | 신청 시 20일 부여 | 1단계+참조1 |
| 보건(생리) | 필수 | 매월 1일 부여 | 1단계+참조1 |
| 보상 | 필수 | 관리자 직접 부여 | 승인 없음 |
| 산전후-본인 | 필수 | 신청 시 90일 | 1단계+참조1 |
| 산전후-미숙아 | 필수 | 신청 시 100일 | 1단계+참조1 |
| 산전후-본인(다태아) | 필수 | 신청 시 120일 | 1단계+참조1 |
| 유산·사산 | 필수 | 신청 시 부여 | 승인 없음 |
| 유산·사산(다태아) | 필수 | 신청 시 부여 | 승인 없음 |
| 결혼-본인 | 자율 | 신청 시 5일 | 1단계+참조1 |
| 결혼-자녀 | 자율 | 신청 시 1일 | 승인 없음 |
| 리프레시 | 자율 | 3년 근속 시 30일(잠김) | 승인 없음 |
| 병가 | 자율 | 연차 소진 시 60일 | 1단계+참조1 |
| 비상 | 자율 | 신청 시 1일 | 승인 없음 |
| 조의-부모/배우자/자녀 | 자율 | 신청 시 5일 | 1단계+참조1 |
| 조의-조부모/형제/자매 | 자율 | 신청 시 3일 | 1단계+참조1 |
| 포상 | 자율 | 관리자 직접 부여 | 승인 없음 |
| **연차** | 정책 | 정책 기반 자동부여 | 연차 정책의 승인선 |

> 우리 시드는 8종 → **누락 보완**: 산전후 다태아·유산사산·유산사산다태아 + 자율 휴가(결혼/리프레시/병가/비상/조의2/포상).

## 2. 데이터 모델 (스키마 설계)

### 2-1. `LeaveType` (맞춤 휴가 = 휴가 종류) — 확장 필요
기존: `key, name, description, isSystem, isRequired, isActive, grantMethod, grantUnit, grantAmount, paymentType, genderRestriction, evidenceRequirement, sortOrder`
**추가:**
- `approverEmployeeId String?` — 휴가별 고정 승인자 ★ (이미 추가됨)
- `ccEmployeeIds String[]` — 휴가별 고정 참조자
- `useUnit LeaveUseUnit` — 사용 단위(한번에모두/나눠서: 일·반차·시간)
- `partialPayPercent Int?` — 일부 유급 % (paymentType=PARTIAL_PAID)
- `deductOnHoliday Boolean` — 휴일 차감 여부
- `excludedEmploymentTypes String[]` / `excludedDepartmentIds String[]` — 제외 대상
- `periodicCycle String?` (반복 부여 주기) / `tenureYears Int?` (근속 시 부여 연수)

> enum `LeaveUseUnit { HOUR, HALF_DAY, DAY }` (추가됨). 부여방법 enum은 기존 `LeaveGrantMethod` 6종 재사용.

### 2-2. `LeavePolicy` (연차 정책) — 확장 필요
기존: `grantMode, fiscalStartMonth, monthlyGrantRule, annualFirstYearRule, decimalRule, expiryMonths, carryoverMaxDays, isDefault`
**추가:**
- `useUnit LeaveUseUnit` + `hourUnitMinutes Int?`(시간 단위 시 1/5/10/15/20/30/60/120분)
- `overdraftMode` (자유/사용량제한) + `overdraftMaxDays Int?` — 당겨쓰기
- `monthlyExpiryMode MonthlyExpiryMode` + `monthlyGraceMonths Int?` — 월차 소멸(추가됨)
- `annualExpiryMode AnnualExpiryMode` + `annualGraceMonths Int?` — 연차 소멸(추가됨)
- `approverEmployeeId String?` / `ccEmployeeIds String[]` — 정책 승인선
- `approveOnRegister Boolean @default(true)` / `approveOnCancel Boolean @default(false)` — 승인 요청 시점
- `smartPromotionEnabled Boolean` — 스마트 촉진 사용
- `grantStartDate DateTime?` — 부여 시작일

### 2-3. `CompanyLeaveSettings` (회사 단위 휴가 설정) — 신규
- `retirementAdjustMode RetirementAdjustMode` — 퇴직자 조정 기준(추가됨)
- 연차 촉진 설정: `promotionApproverEmployeeId`, `promotionCcEmployeeIds[]`, `memberRemindEnabled`, `adminRemindEnabled`, `planNoticeDaysBefore`(1/3/5/7/10), `annualPromotionTiming`(소멸6개월전 +0/5/10일), `monthlyPromotion1Timing`(소멸3개월전…), `monthlyPromotion2Timing`(소멸1개월전…)

### 2-4. `LeavePromotion` (연차 촉진) — 신규 ★ (촉진 엔진 핵심)
- `employeeId, year, promotionType`(ANNUAL/MONTHLY_1ST/MONTHLY_2ND), `targetDays`(촉진 대상 일수), `expiryDate`(법정 소멸일), `status`(촉진 진행 상태머신 ↓), `requestedAt`, `submittedAt`, `approvedAt`, `formDocumentId`
- 진행 상태(Flex 7종): `작성요청됨 / 관리자작성기간 / 승인진행중 / 반려 / 완료 / 작성기간지남 / 촉진취소`
  - 우리 디자인은 4-status 칸반(대기/진행/완료/종료)으로 그룹핑하되 내부 status는 7종 보존
- 하위 `LeavePromotionPlanDate` — 사용 희망일 목록(여러 날짜)

### 2-5. `LeaveRequest` — 사용 단위 정보 추가
- `unitType`(FULL/AM_HALF/PM_HALF/HOURLY) + `startTime`/`endTime`(시간차) + `evidenceFileUrl`

## 3. [설정] 연차 설정 (settings=annual-time-off)

### 3-1. 메인 페이지
- 섹션 **연차 정책** + `+ 연차 정책 추가` 버튼
  - 정책 카드 컬럼: `부여 기준일`(회계일/1월1일) · `사용 단위`(반차 단위) · `승인·참조`(1단계+참조1) · `스마트 연차 촉진`(사용 중 ●)
  - 카드 우측: 사용중 구성원 아바타 +N명
- 섹션 **연차 설정** (하위 항목 리스트):
  - `퇴직자 연차 조정 기준 설정` → "구성원에게 유리한 기준으로 적용 >"
  - `연차 촉진 설정` → ">"

### 3-2. 연차 정책 편집 모달 (이벤트: 정책 카드 클릭 / 추가)
헤더: 정책명(편집) + 설명 입력 + 사용중 구성원 아바타

**기본 설정**
| 필드 | 동작/옵션 |
|---|---|
| 승인·참조자 선택 | → 승인·참조자 선택 서브모달(§7) |
| 승인 요청 시점 | 토글 ①`휴가를 등록할 때`(ON) ②`등록한 휴가를 취소할 때`(OFF) |
| 연차 사용 단위 | 세그먼트 `시간`/`반차`/`일`. 시간 선택 시 하위 드롭다운: 1분/5분/10분/15분/20분/**30분(추천)**/1시간/2시간 |
| 당겨쓰기 설정 | 드롭다운: `자유롭게 사용 가능` / `사용량 제한`(→최대 사용량 N일 입력). 안내: "보유 연차 소진 시 다음 부여분에서 최대 N일까지 당겨쓸 수 있어요." |

**연차 부여·소멸 설정**
| 필드 | 동작 |
|---|---|
| 연차 부여 방식 | → 부여 방식 서브모달(§3-3) |
| 자동 소멸 설정 | → 자동 소멸 서브모달(§3-4) |
| 스마트 연차 촉진 | 드롭다운 `사용 중`. 펼침: 기능 사용 토글 + 연차(소멸6개월전)·월차1차(소멸3개월전)·월차2차(소멸1개월전) 요약 + "요청 시점 변경 ↗"(→§3-6) |

하단 `저장하기`. 이탈 시 확인: "정말 그만할까요? / 지금 종료하면 수정 중인 연차 정책이 저장되지 않아요." [그만하기/취소]

### 3-3. 연차 부여 방식 서브모달
헤더: `📅 부여 시작일: YYYY년 M월 D일` / 탭 `회계일`·`입사일`
- **회계일 탭** 안내: "연차가 일괄 부여되니 부여, 촉진 등의 관리가 쉬울 수 있어요. 단, 취업규칙에 회계 연도 기준… 퇴직시에는 입사일 부여 기준으로 재계산 정산 필요."
  - `회계일` 드롭다운: 1월1일~12월1일
  - `입사자 월차`: 매월 개근시 1일 부여 / 입사일에 11일 선부여 / 입사일에 회계일까지 월차 선부여
  - `입사자 1년 만근 연차`: 첫 회계일에 15일 부여 / **첫 회계일에 근무한 기간의 연차 부여(추천)** / 입사일에 회계일까지 연차 선부여
  - `소수점 이하 연차`: **일 단위 올림 처리(추천)** / 연차 단위 올림 처리 / 조정 안 함
  - `더 많은 설정 확인하기` + **연차 자동 부여 미리보기** 테이블(날짜/월차/연차)
- **입사일 탭** 안내: "입사하는 날 기준으로 연차 자동 부여. 구성원마다 부여일·촉진 시점 상이." + 입사자 월차 / 입사자 1년 만근 연차(1년 만근시 15일 부여)

### 3-4. 자동 소멸 설정 서브모달
- **미리보기 테이블**: 행 `법정 소멸일`·`실제 소멸일` × 열 `월차`·`연차`
  - 법정 소멸일 툴팁: "근로기준법 상 최소한으로 보장해야하는 소멸 시점. 연차 촉진도 이 기준으로 실행…"
  - 실제 소멸일 툴팁: "실제 소멸 시점. 법정 소멸일보다 이르게 설정할 수 없어요."
- **월차**: 자동 소멸 시점(`소멸 안 함`/`입사일로부터 1년 후`/`입사일로부터 1년 후 첫 회계일`) + 소멸 유예 기간(`유예기간 없음`/19~24개월)
- **연차**: 자동 소멸 시점(`소멸 안 함`/`부여일로부터 1년 후`) + 소멸 유예 기간(동일)

### 3-5. 퇴직자 연차 조정 기준 모달
라디오: ①`구성원에게 유리한 기준으로 적용`[기본] — "근로기준법 기준과 실제 회사 부여량 중 더 큰 값" ②`항상 근로기준법 기준으로 적용`
+ 예시 테이블(구성원/근로기준법 부여량/실제 회사 부여량). 버튼 `변경 사항 적용하기`

### 3-6. 연차 촉진 설정 모달
- `승인·참조 대상` → 승인·참조자 선택 서브모달
- `구성원 작성 리마인드`(토글) — "사용 계획 작성 알림을 제출 기한 동안 매일"
- `관리자 작성 리마인드`(토글)
- `사용 계획일 알림 시점`: 1일/3일/5일/7일/**10일** 전
- **스마트 연차 촉진**:
  - `연차 촉진 시점`(1년 이상): 소멸 6개월 전 / +5일 후 / +10일 후
  - `월차 촉진 시점`(1년 미만): 1차 소멸 3개월 전(+5/+10) · 2차 소멸 1개월 전(+5/+10)
  - 안내: "스마트 연차 촉진은 소멸 유예 설정과 관계없이 법정 연차 소멸일 기준 실행"
- 버튼 `변경 사항 저장`

## 4. [설정] 맞춤 휴가 (settings=custom-time-off)

### 4-1. 메인 — 휴가 종류 목록
- `+ 맞춤 휴가 추가` 버튼
- 행: 드래그 핸들 + 휴가명 + [필수] 뱃지 + 설명 + 우측 승인/참조 뱃지(`1단계 승인`/`참조 1` 또는 `승인 없음`/`참조 없음`) + `···`

### 4-2. 맞춤 휴가 추가/편집 모달 (이벤트별 동적 폼)
- 이름 + 설명
- `부여 방법`: **조건에 따라 부여**(신청 시/연차 소진 시/관리자 직접/입사 시) · **주기 단위로 부여**(반복 부여→반복주기 / 근속 시→부여 시점)
- `부여 단위`: 분/시간/일/신청하는 만큼
- `부여 시간`: 숫자 + 단위 (관리자 직접 부여 시 부여단위·시간 숨김)
- `사용 단위`: `한번에 모두 사용`(→ "일부만 사용 시 나머지 자동 소멸") / `나눠서 사용`(일 1·0.5일 / 반차 오전·오후 / 시간차 제한없음·5·10·15·20·30분·1·2시간)
- `급여 지급 유무`: 유급/무급/일부 유급(% 입력)
- `승인·참조 사용` ★ → 승인·참조자 선택 서브모달 (여기서 지정 → **이 휴가 신청 시 고정 적용**)
- **추가 설정**(접이식):
  - `사용 가능 성별`: 모두/남성/여성
  - `증명 자료 제출`: 없음/사전 제출/사후 제출
  - `제외 대상 설정`: 근로유형(정규/계약/파견/일용/프리랜서/등기임원/비등기임원/위촉직) + 조직 피커
  - `휴일에 등록된 휴가 차감`(토글)
- 버튼 `만들기`. 이탈 확인: "변경사항을 저장하지 않고 나가시겠어요?" [나가기/이어서 진행하기]

## 5. [구성원] 내 휴가 (my-time-off)

### 5-1. 탭: 휴가 개요 / 연차 상세 / 연차 사용 계획

### 5-2. 휴가 개요 — 휴가 등록
- 섹션 `휴가 등록`: 휴가 종류 카드 그리드(연차 0일, 가족돌봄 신청시 1일 부여 …). 잠김 휴가는 🔒. `모두 보기/접기`
- 섹션 `사용한 기록`: `반려 기록 포함` 토글 + 연도 셀렉터 + 빈 상태 "예정된 휴가가 없습니다."

### 5-3. 휴가 신청 모달 (이벤트: 카드 클릭) ★ 핵심 플로우
헤더: `휴가명 · 사용 가능 · 유급/무급`
1. **날짜 선택**: 듀얼 캘린더(이번달·다음달). 시작일 클릭 → 종료일 클릭. **같은 날 두 번 = 하루** → 하단에 사용 단위 라디오 노출
2. **사용 단위 라디오**:
   - `하루 종일`
   - `오전 반차` — 시작/종료 시간(예 09:00~14:00) + ☕(휴게 1시간 포함)
   - `오후 반차` — 14:00~18:00 + ☕(미포함)
   - `시간차` — 시작/종료 시간 드롭다운 + ☕(툴팁 "휴게 시간을 포함했어요/안했어요")
3. `다음` 버튼
4. **확인 화면** "휴가를 등록할까요?":
   - 요약(날짜·단위·시간) + `다시 선택하기 >`
   - `증명 자료`[나중 제출 가능] — 파일 드롭존 (evidenceRequirement≠없음 시)
   - `사유` — "휴가 사용 기록에 남길 수 있어요."
   - 결재자 안내: "OOO님에게 승인을 요청해요. >" (휴가별 고정 승인자)
   - 버튼 `승인 요청하기`

### 5-4. 연차 상세 탭
- 요약 카드: 이용 가능 / 사용 / 예정 / 소멸 (또는 자동부여/소멸/사용/조정)
- 월별 원장 테이블: `날짜 | 자동부여 | 소멸 | 사용 | 조정 | 잔여` (입사월 뱃지, 현재월 강조, 누적 잔여)
- 연도 셀렉터 + 하단 "소수점 넷째 자리에서 반올림하여 표기한 결과입니다."

### 5-5. 연차 사용 계획 탭
- 조회 기간(연도)
- 빈 상태: "연차 촉진 내역이 없어요. / 담당자가 연차 촉진을 시작하면 이 곳에서 연차 사용 계획을 작성할 수 있어요."
- 촉진 있을 시: 사용 계획 작성 폼(사용 희망일 N개 선택 → 제출 → 결재)

## 6. [관리자] 휴가 관리 (근태 관리 > 휴가 관리)

### 6-1. 탭: 휴가 보유 현황 / 휴가 사용 내역 / 월별 연차 사용 내역 / 연차 촉진

### 6-2. 휴가 보유 현황
- 상단: `맞춤 휴가 부여 ▾`(+맞춤휴가부여 / 부여 내역) · `연차 조정 ▾`(연차 조정 / 재직자 정산용 / 퇴직자 정산용)
- 필터: 조직 ▾ + 필터 추가 + 검색
- 테이블: 이름/사번/연차 + 18종 휴가 컬럼(각 부여 정책 보조설명). → **우리 디자인은 6컬럼 + side sheet**(docs/08 §7-2)
- **맞춤 휴가 부여 모달**: 휴가 종류 / 부여 시간(+단위) / 부여 대상 / 사용 가능 기간(언제든/기간지정) + 엑셀 일괄. 안내: "보상 휴가·신청 시 부여 제외하고 부여 가능"
- **연차 조정**: 수동 부여·차감 / 재직자·퇴직자 정산용 잔여 조정

### 6-3. 휴가 사용 내역
- 필터: 조회 기간 / 조직 / + 필터
- 테이블: 이름/사번/기간/항목/사용시간/상태(`휴가취소`/`승인완료`)/증명(`제출`)

### 6-4. 월별 연차 사용 내역
- `연차 사용 내역 업로드` 버튼
- 테이블: 이름/사번/입사일/잔여 연차/1~12월
- **업로드 모달**: 단위 토글(일·시간·분 / 소수점) → 엑셀 양식 다운로드 → 파일 업로드. 안내: "근무·휴가 기록이 없는 날에만 기록 가능"

### 6-5. 연차 촉진 ★
- 상단: `촉진 설정`(→§3-6) · `연차 사용계획 …`
- 필터: 조회 기간 / 조직 / 재직 상태 / 진행 상태 ▾
- 테이블: ☐/재직상태/이름/사번/촉진 유형(월차1차·월차2차·연차)/소멸일/진행 상태/사용 계획(보기)/···
- **진행 상태 7종**: 작성요청됨 / 관리자작성기간(N일 남음) / 승인진행중 / 반려 / 완료 / 작성기간지남 / 촉진취소
  - 진행 상태 필터: 그룹 `진행 중`(작성요청됨/관리자작성기간/승인진행중/반려) · `종료`(완료/작성기간지남/촉진취소)
- 행 `···`: 촉진 취소
- **연차 사용 계획 상세**(보기): 이름/계획 대상 연차/사용 희망일(N개)/활동 로그/승인·참조(단계별 완료) + 댓글

## 7. 승인·참조자 선택 서브모달 (공통 컴포넌트) ★

모든 곳에서 재사용(연차 정책 / 맞춤 휴가 / 촉진 설정). = 우리 `RecipientPicker` 통합 대상(Anti-Pattern #10).
- 상단 칩: `요청자별 승인` / `변경 허용`
- 섹션 `참조`(+): 참조자 N명, 각 `알림 ▾`(승인 요청·완료 시 알림 / 승인 완료 시 / 알림 없음)
- 섹션 `1 단계 승인`(+): 승인자, `승인 ▾`
- `+ 승인 단계 추가하기` (N단계)
- 대상 피커: 검색 / 조직도 보기 / 1~5차 조직장 / 조직 트리 / 구성원 목록 / `하위 조직 함께 선택`
- 버튼 `확인`

## 8. 연계 (Interconnection) — 휴가가 다른 도메인과 엮이는 지점

### 8-1. 휴가 신청 → 워크플로우(결재)
- 신청 → `FormDocument`(kind=LEAVE_REQUEST) 생성 → 휴가 종류/연차 정책에 **고정된 승인선**으로 `ApprovalLine` 자동 생성
- 워크플로우 `내 문서함`/`회사 문서함`에서 승인/반려
- 최종 승인 → `finalizeLeaveFromApprovedDocument` → `LeaveTransaction(USE)` + 잔액 차감
- 반려 → `finalizeLeaveFromRejectedDocument`

### 8-2. 승인 정책 관리 (settings=approval-policy)
- 탭: 워크플로우 / 근무 / **휴가**(20종) / 구성원 정보
- 휴가 탭의 각 정책 = 맞춤휴가/연차정책에서 설정한 승인선과 동기화

### 8-3. 알림 (Notification)
- 휴가 승인 요청(승인자에게) / 승인 완료(신청자에게) / 반려
- 촉진: 작성 요청 / 작성 리마인드(매일) / 사용 계획일 N일 전 / 관리자 대리작성 통보
- → `apps/worker` 스케줄러가 촉진/소멸/리마인드 자동 실행

### 8-4. 구성원 프로필 → 휴가 정보
- 프로필 `휴가 정보`: 연차 정책(회계일 기준/반차 단위/연차 촉진 사용) 표시
- 정보 일괄 변경 → `연차 정보 변경` 경로

### 8-5. 자동부여/소멸/촉진 엔진 (worker)
- 연차 자동부여(정책 기반, 멱등) — MVP 구현됨
- 자동 소멸(월차/연차 분리 + 유예) — 확장 필요
- 스마트 촉진(소멸 6/3/1개월 전 자동 발동) — 신규
