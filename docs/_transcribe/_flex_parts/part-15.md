  - 우: `권한 설정` + `→` / 보조라벨 `다음으로`
  - (= 설정 섹션을 순서대로 넘기는 "이전/다음" 내비. 좌측 GNB 순서와 동일)

- `임시 비밀번호 발급` = 관리자 대행 비번 리셋. 본인 인증 불가 상황 대비.
