## 공통 레이아웃·디자인 (settings 패널)

- **두 가지 표현 방식이 혼재**:
  1. **소형 센터 모달** — 단순 분류 항목 편집용(직위/직책/직무/직군/직급, 라벨 추가, 승인 정책 상세, 기본 문서 추가). 화면 중앙 흰 카드, 모서리 둥근(radius ~12px), 우상단 `×` 닫기. 하단에 녹색 `설정 저장`/`저장하기` 버튼이 카드 footer 에 sticky.
  2. **대형 풀패널(좌측 GNB 유지)** — 종합 설정 페이지(인사·구성원 정보, 승인 정책 관리, 커스텀 승인 라벨, 문서함 설정). 좌측에 설정 GNB 사이드바, 본문은 흰 배경 넓은 영역, 우상단 `×`.
- **좌측 설정 GNB 구조** (그룹 헤더 = 회색 소문자 캡션, 항목 = 아이콘+라벨, 활성 항목은 연회색 배경 pill):
  - **기본 정보**: `회사 정보` / `쉬는 날` / `회사 직인` / `계열사 관리`
  - **인사·계약**: `인사 · 구성원 정보` / `문서함 설정`
  - **승인관리**: `승인 정책 관리` / `커스텀 승인 라벨`
  - **근무**: `근무 유형` / `근무 정책 · 승인` / `초과 근무 보상` / `근무지`
  - **휴가**: `연차 설정` / (이하 잘림)
- 페이지 하단에는 **이전/다음 네비 카드** 2개 (좌: `← 이전으로`, 우: `다음으로 →`) — 설정 항목 순서대로 wizard 처럼 이동 가능. 예: 인사·구성원 정보 페이지 하단 = 좌 `회사 직인 / 이전으로`, 우 `문서함 설정 / 다음으로`.
- 아이콘 = 컬러 이모지/Lucide 혼용. 분류 항목 행은 가로 풀폭 리스트, hover 시 우측에 액션 아이콘(휴지통 등) 노출.
- 녹색 CTA(저장 버튼)는 좌→우 살짝 그라데이션(민트→그린)도 보임 — flex 시그니처.

## [18:17:12] 직위 설정 모달

**화면 식별** — 인사·구성원 정보 > 분류 설정 중 **직위(Rank/Position title)** 편집 소형 모달. URL `?settings=hr-information`.

**레이아웃** — 우상단 아이콘 버튼들: 돋보기(검색) · `+`(추가) · `×`(닫기). 좌상단 노란 라벨 아이콘 + 제목 `직위 설정` + `ⓘ` 도움말 아이콘. 본문은 항목 리스트(행 구분선). 하단 footer 녹색 `설정 저장`.

**verbatim**
- 제목: `직위 설정`
- 카운트: `총 2개`
- 항목: `대표`, `이사`
- 플레이스홀더(새 행 입력): `직위 입력 (대리, 과장 등)`
- 버튼: `설정 저장`

**이벤트** — `ⓘ` hover 시 직위 정의 툴팁(추정). 행 hover 시 우측 휴지통 삭제 아이콘. `+` 또는 플레이스홀더 행 클릭 → 신규 직위 인라인 추가.

**왜(rationale)** — 한국 기업 인사체계는 **직위(대리·과장·차장·부장 등 연공/호칭)**, **직책(팀장·실장 등 보직)**, **직급(사원·주임 등 등급)**, **직무(직종)**, **직군(직무 묶음)**을 별도 축으로 관리한다. flex 는 이 5축을 각각 독립 마스터로 둠. 직위는 명함·호칭·예우와 직결되고 시점 이력(승진) 대상이라 별도 테이블 필요. → Teamlet 의 `PositionHistory` / 분류 마스터 설계 근거. 기본 제공값이 `대표/이사`인 것은 임원 호칭 시드.
