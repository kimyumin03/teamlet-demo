## 부록 — Teamlet 적용 메모(요약)
- **임금 이력**: 시작일(적용일)만 입력, 종료일은 "다음 계약 시작일−1일" 자동 파생(개인 폼). 벌크는 직접 입력 허용(마이그레이션).
- **소득구분/지급단위/근로유형**은 enum 마스터로 — 하드코딩 금지(가산배율 +50/+100/+150% 도 테이블화).
- **포괄임금**: 가산항목 6종 × (계약시간/가산시간) + 월52h·주12h 한도 인라인 검증.
- **인사 5축**: 직책·직위·직급·직무(다중)·직군 독립 + 모두 시점("YYYY년 M월 D일 OOO" 라벨) 기준. 마스터 미구성 시 인라인 "+ 추가하기".
- **벌크**: `BulkOperation`+Row, 입력상태(전체/입력됨/오류) 필터, 재직상태 카운터, 컬럼 프리셋(입력 정보 설정 패널, 드래그·눈 토글, 필수 3종 고정).
- **겸임 발령** 별도 항목 = 겸직 이력 모델 필요.
