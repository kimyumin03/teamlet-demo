- **주 버튼**: Flex 초록~청록 그라데이션 → Teamlet 은 `bg-primary`(Slate 900) 단색. **파괴 버튼**(나가기) 주황 → destructive 토큰.
- **슬라이드 패널 + 3스텝 탭**(공고 본문/전형단계/지원정보): 좌측 목록 유지하며 우측 패널 편집 = 컨텍스트 보존 UX. RecipientPicker/공통 피커 재사용 원칙과 별개로, 채용 폼 빌더는 동적 행(+추가/삭제) 패턴 표준화 필요.
- **검색형 드롭다운**("…검색 또는 추가"): 직무/직군/전형단계 모두 동일 컴포넌트 → 마스터데이터 누적형. 1개 컴포넌트로 통합 권장.
- **이탈 가드 다이얼로그**: 미저장 폼 공통 패턴.
- **빈 상태 + 다음 액션 버튼**: "아직 공고가 없어요 → 공고 탭으로 이동하기" 식 가이드.
- **설정 메뉴 그룹핑**(공고 설정/사이트 설정/권한 설정): 채용 설정 허브 구조 차용.
- **문서·증명서**: 법정 의무 교육/규약을 회사 문서 카탈로그로 시드화하면 한국 기업 범용성↑.
