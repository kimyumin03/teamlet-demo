# flex 전사 — part 01 (batch-01, 24장)

> 분석 대상: `flex.team` 홈 피드(회사 소식·할 일) 및 "동료에게 전달하기" 작성 플로우 전체.
> 캡처 순서 = 사용자의 실제 네비게이션 흐름. 홈 진입 → 공지사항 작성 모달 → 수신자 피커 → 회사소식 탭(공지/인정) → 할일 탭(해야할일/요청한일/참조) → 할일 요청 작성 → "동료에게 전달하기" 5종 액션.
> verbatim 문구는 모두 따옴표로 인용. 흐릿하게 축소된 캡처(파일 피커·수신자 트리 일부)는 인접 선명 캡처로 보완.

## 공통 레이아웃·디자인 참고 (전 화면 공통 셸)

**상단 브라우저 탭/주소 (참고용, 제품 아님)**: Chrome. 주소창에 `flex.team/home` 등.

**좌측 GNB (Global Nav, 세로 사이드바)** — 순서대로:
- 상단 워크스페이스 스위처: 초록 사각 로고 + `"주식회사 대모산개발단"` (회사명/테넌트)
- 그 아래 드롭다운: `"근무중 자동 기록 중"` + 펼침 화살표 (근무 상태 토글 — 추정: 출퇴근/근무기록 상태 선택)
- 메뉴 항목 (아이콘 + 라벨, 위→아래):
  1. `"내 프로필"`
  2. `"검색"` (우측에 `Ctrl K` 단축키 배지)
  3. `"알림"` (벨 아이콘)
  4. `"홈 피드"` (집 아이콘, 현재 선택 — 옅은 회색 배경 하이라이트 + 좌측 약간의 강조)
  5. `"구성원"`
  6. `"근무"`
  7. `"휴가"`
  8. `"근태 관리"`
  9. `"워크플로우"`
  10. `"후보자 평가"`
  11. `"채용"`
  12. `"인사이트"`
  13. `"문서·증명서"`
  14. `"설정"`
- 하단 섹션 구분선 아래: `"추가 기능"` (펼침 화살표 ⌄), 그 아래 흐릿한 `"단체 보험"` (추가 기능 진입점, 회색 비활성/하위 메뉴 느낌)

**메인 헤더(콘텐츠 영역 최상단)**: 큰 글씨 가로 탭 — `"홈 피드"`(현재) · `"회사 소식"` · `"할 일"`. 선택된 탭은 진한 검정, 비선택은 옅은 회색.

**우상단 CTA 버튼**: 초록→청록 그라데이션 알약(pill) 버튼 + 깃발 아이콘, 라벨 `"동료에게 전달하기"`. (※ Teamlet 금지 패턴: Flex 시그니처 초록 그라데이션. 우리는 Slate 단색 CTA로 대체.)

**디자인 톤**: 전체 흰 배경, 매우 낮은 채도, 얇은 회색 구분선, 카드 모서리 둥글게(약 8~12px), 그림자 거의 없음. 폰트는 가는~중간 굵기 산세리프. 강조색은 거의 초록(=Flex 브랜드). 모달은 중앙 정렬 흰 카드 + 외곽 반투명 딤(dim) 오버레이, 우상단 X 닫기.

## [171544] 홈 피드 — 기본 진입 (빈 상태)

- **화면 식별**: 홈 피드 도메인 / URL `flex.team/home` / 탭 = `"홈 피드"` 활성.
- **레이아웃**: 3단 구성. (좌) GNB · (중) 메인 피드 · (우) 위젯 사이드바.
- **중앙 메인 — 공지사항 빈 상태**:
  - 섹션 헤더 `"공지사항 (0)"`, 우측 `"더 보기"` 링크.
  - 중앙 빈상태 카드: 연필 일러스트 아이콘, 제목 `"공지사항을 작성해볼까요?"`, 부제 `"우리 회사 구성원들에게 알려주고 싶은 내용을 공지사항으로 작성해보세요!"`, 검정 외곽선 버튼 `"작성하기"`.
- **우측 사이드바 위젯 2종**:
  1. `"인정과 피드백"` 위젯 — 박수/하이파이브 이모지 일러스트, 제목 `"동료들을 응원해요!"`, 설명 `"함께하는 동료들에게 인정 메시지를 보낼 수 있어요."`, 링크/버튼 `"인정 보내기"`.
  2. 캘린더 위젯 — `"2026년 5월"` 헤더, 좌우 이동 화살표 + `"오늘"` 바로가기. 요일 헤더 `일 월 화 수 목 금 토`, 날짜 그리드(17~23 행 보임), 오늘(22)에 초록 원형 강조. 하단 `"일정이 없어요."` 빈 상태 + 버튼 `"일정 보기"`(캘린더 아이콘).
- **이벤트**: `"작성하기"`/`"동료에게 전달하기"` → 작성 모달. 캘린더 `"일정 보기"` → 일정 뷰.
- **왜(rationale)**: 홈 피드는 HR SaaS의 "사내 인트라넷 첫 화면" 역할. (1) 공지사항 = 전사 커뮤니케이션 단일 채널(이메일 산재 방지, 도달·열람 추적). (2) 인정/피드백 = 조직문화·engagement 기능(피플팀 KPI). (3) 캘린더 = 본인/팀 휴가·일정 가시화로 근태와 연동. 빈 상태에 "작성하기"를 강하게 노출 = 신규 도입 회사의 콜드스타트 유도(UX 의도).

## [171611] 공지사항 작성 모달 (열린 직후)

- **화면 식별**: 홈 피드 위 중앙 모달 "공지사항 작성".
- **이벤트 맥락**: 직전 화면의 `"작성하기"`(또는 `"동료에게 전달하기"`>공지) 클릭 → 모달 오픈. 배경은 딤 처리.
- **모달 구성(위→아래)**:
  - 우상단 X 닫기.
  - 제목 입력 (플레이스홀더) `"공지사항 제목"` (큰 회색 글씨).
  - 수신자 선택 줄: 사람 아이콘 + `"받는사람 선택"` (클릭 시 피커 오픈).
  - 본문 영역 플레이스홀더 `"동료에게 보낼 공지사항 내용을 작성해 주세요."`.
  - 첨부 영역 카드: 파일 아이콘 + `"첨부파일 추가"`, 보조설명 `"이미지, PDF, Zip 등을 첨부할 수 있어요."`, 우측 `+` 버튼.
  - 하단 풀폭 CTA (초록 그라데이션) 연필 아이콘 + `"작성하기"`.
- **왜**: 공지 = 제목+본문+수신자+첨부의 4요소. 수신자 선택을 명시 노출 = 전사/부서/개인 타겟팅(불필요 알림 최소화). 첨부 허용 포맷 안내 = 업로드 실패 사전 예방 UX. (Teamlet: 우리 `RecipientPicker` 재사용 대상 — anti-pattern #10.)

## [171643] OS 파일 선택 대화상자 (첨부파일 추가 클릭)

- **화면 식별**: 제품 화면 아님 — Windows 탐색기 "열기" 파일 피커. 직전 모달의 `"첨부파일 추가"`/`+` 클릭으로 호출됨.
- **내용**: 좌측 탐색기 트리(바탕 화면/OneDrive/내 PC/다운로드 등), 우측 파일 목록(스크린샷·이미지 파일들), 하단 `파일 이름:` 입력 + `열기`/`취소` 버튼. (모두 OS UI.)
- **왜(rationale)**: 첨부 업로드가 네이티브 파일 선택을 트리거함을 확인. Teamlet 구현 시 `<input type=file>` accept 필터(이미지/PDF/Zip)와 일치시킬 근거.
- **특이사항**: 제품 UI가 아니므로 디자인 전사 대상 제외.

## [171711] 공지 작성 모달 — 받는사람 선택 피커 (열림)

- **화면 식별**: 공지 작성 모달 위에 겹쳐 뜬 수신자 선택 팝오버/패널.
- **이벤트**: 모달의 `"받는사람 선택"` 클릭 → 좌측 조직 트리 패널 펼침.
- **피커 구성**:
  - 상단 검색 입력 (돋보기) 플레이스홀더 `"검색"`.
  - 우측 상단 토글/탭 `"목록 보기"`, 그 옆 `"선택없음"` (현재 선택 0 표시).
  - 좌측 트리 루트 `"(주)대모산개발단"`, 하위 부서 노드(펼침 ▸): `"디자인팀"`, `"개발팀"`, `"교육팀"`, `"이사"`.
  - 부서 아래 개인 목록(아바타+이름): `"강수빈"`, `"고성현"`, `"김학윤"`, `"김세찬"`, `"김수로"`, `"박민영"`, `"이원길"`, `"장태준"`, (이하 `"저(...)"` 스크롤로 잘림).
  - 패널 하단 체크박스 옵션 `"하위 조직 함께 선택"` (초록 체크, 기본 ON으로 보임).
- **왜**: 조직 계층 기반 수신자 선택 = 한국 기업 부서 트리 구조 반영. `"하위 조직 함께 선택"` = 상위 부서 선택 시 산하 전원 포함(반복 클릭 제거). 검색+트리 병행 = 대규모 인원 대응. (Teamlet 멀티테넌시: 루트가 회사명 = `companyId` 스코프.)

## [171844] 할 일 — 요청한 일 탭 (1건)

- **화면 식별**: 할 일 / URL `flex.team/home/todo/sent` / 서브탭 `"요청한 일"` 활성.
- **목록**:
  - 그룹 헤더 `"종료 (1)"` (완료/종료된 요청 그룹, 좌측 정렬 아이콘).
  - 행: 아바타 `"송재희"` · 제목 `"'5월 26일 연차 (1일)' 승인 요청"` · 우측 메타 배지 `"휴가 승인 요청"` · 시간 `"2시간 전"`.

## [172246] 피드백 메시지 보내기 — 받는사람 선택 피커

- **화면 식별**: 피드백 모달 위 수신자 피커 — 동일 RecipientPicker.
- **구성**: 검색 입력 · `"목록 보기"` · `"선택없음"` · 트리 루트 `"(주)대모산개발단"` + 부서 + 개인 아바타 목록 + 하단 `"하위 조직 함께 선택"` 체크. (초록 강조 톤.)
- **특이사항**: 캡처 축소로 글자 일부 흐림 — 구성은 [171725]/[172208]과 동일.

## 종합 — Teamlet 구현 시사점

1. **RecipientPicker 단일화**: 조직 트리(회사 루트 → 부서 ▸ → 개인) + 검색 + `"하위 조직 함께 선택"` + 좌(소스)/우(선택결과) 2-pane. 공지·할일·인정·피드백·문서요청 전부 재사용 (anti-pattern #10 준수).
2. **발신 허브("동료에게 전달하기")**: 공지/할일/문서작성/인정/피드백 5분기. 단, **컬러풀 아이콘 카드는 Flex 시그니처 → Slate 모노 Lucide로 변주**.
3. **할 일 = 워크플로우 통합 입증**: "요청한 일"에 휴가 승인 요청이 섞임 → 휴가/문서/할일이 한 결재 엔진. Teamlet `FormDocument.document_kind` 설계 정당화.
4. **마감일 프리셋 + 직접입력 토글**, **이탈 확인 다이얼로그**(파괴 버튼 경고색) = 공통 폼 UX 패턴으로 채택.
5. **금지/변주**: 초록→청록 그라데이션 CTA 전면 등장 → Teamlet은 Slate 900 단색으로 전량 대체.
