## [174522] 인사 발령 — 발령 정보 설정 모달 (1단계)

**화면 식별** — 도메인: 구성원 > 인사 정보 관리 > 인사 발령 탭. URL: `flex.team/people/manage/personnel-appointment`. 상단 페이지 헤더에 "구성원 · 조직도 · 인사 정보 관리"(인사 정보 관리가 활성), 우측 상단 녹색 버튼 "정보 변경하러 가기"(추정). 모달 = **발령 정보 설정**.

**레이아웃·디자인** — 화면 중앙에 흰색 카드형 모달(라운드 코너, 우상단 회색 원형 X 닫기). 모달 폭은 본문의 절반 정도. 배경은 디밍 처리. 입력 필드는 라운드 박스(연회색 배경), 라벨은 좌상단 + 필수는 빨강 `*`. 하단 CTA = 풀폭 녹색 버튼(Flex 시그니처 초록→청록 그라데이션).

**verbatim**
- 제목: "발령 정보 설정"
- 안내: "인사 발령에 필요한 정보를 먼저 설정해 주세요."
- 필드1 라벨: "발령일 *" / 값: "2026. 5. 22"
- 필드2 라벨: "발령 대상 *" / 플레이스홀더: "발령 대상 선택"
- 필드3 라벨: "발령 라벨 ⌄(? 도움말 아이콘)" / 플레이스홀더: "발령 라벨 선택"
- 필드4 라벨: "메모" / 우측 보조: "🔒 인사 정보 권한자만 볼 수 있어요." / 플레이스홀더: "메모를 입력하세요."
- CTA: "정보 변경하러 가기"

**이벤트** — CTA 클릭 시 발령 대상의 실제 정보 변경 화면으로 진입(2단계). 각 셀렉트는 클릭 시 드롭다운/캘린더 오픈(아래 174530~174547 참조).

**왜(rationale)** — 한국 HR에서 "발령(인사발령)"은 채용·승진·전보·휴복직·퇴직 등 신분 변동을 공식 기록하는 행위. **발령일**을 먼저 고정하는 이유는 시점 기반 이력(특정일자에 효력 발생)을 보장하기 위함 — Teamlet의 `Appointment` 트랜잭션 + `PositionHistory` 새 row 설계와 정확히 일치(UPDATE 금지 원칙). **발령 라벨**은 발령 사유 분류(전보/조직변경 등)로 통계·증명서 출력에 쓰임. **메모에 권한 잠금 문구**는 인사정보가 민감정보(개인정보보호법)임을 반영 — 인사 권한자 외 비공개.

## [174530] 발령 정보 설정 — 발령일 캘린더 (date picker)

**화면 식별** — 위 모달에서 "발령일" 셀렉트 클릭 → 단일 캘린더 팝오버.

**레이아웃·디자인** — 셀렉트 바로 아래에 흰 카드 팝오버. 상단에 텍스트 입력형 날짜("2026년 5월 22일"), 그 아래 보조문구 + 우측 "초기화" 링크. 월 네비게이션(‹ 2026년 5월 ›). 요일 헤더 "일 월 화 수 목 금 토"(일요일 회색). 선택일 22 = 녹색 강조 알약.

**verbatim**
- 입력값: "2026년 5월 22일"
- 보조: "선택 입력이에요." / 링크: "초기화"
- 월 헤더: "2026년 5월" (‹ › 이동)
- 요일: "일 월 화 수 목 금 토"

**이벤트** — 날짜 클릭 → 발령일 확정, 팝오버 닫힘. ‹ › 로 월 이동. "초기화"로 입력 비움.

**왜** — 발령은 미래·과거 일자 모두 가능(예: 다음 달 1일 자 승진 예약). "선택 입력" 문구는 빈 값 허용을 시사하나 발령일은 필수(`*`)라 모순적 — 추정: 텍스트 직접입력 보조 안내. Teamlet은 예약 발령(effective_date 미래) 지원 필요.

## [174539] 발령 정보 설정 — 발령 대상 선택 드롭다운 (RecipientPicker)

**화면 식별** — "발령 대상" 셀렉트 클릭 → 대상 선택 패널(좌: 검색/트리, 우: 선택 결과).

**레이아웃·디자인** — 2분할 팝오버. 좌측 상단에 검색 인풋(돋보기 + "검색", 포커스 시 녹색 보더) + 우측 "조직도 보기" 버튼. 그 아래 리스트: "전체 구성원"(빌딩 아이콘) → 섹션 "조직"(조직 아이콘별 컬러칩) → 섹션 "직위". 우측 패널 헤더 "선택없음".

**verbatim / 옵션 전체**
- 검색 placeholder: "검색" / 버튼: "조직도 보기"
- 우측 패널 상태: "선택없음"
- 최상단 항목: "전체 구성원"
- 섹션 "조직": "(주)대모산개발단", "디자인팀", "개발팀", "교육팀", "프론트엔드"
- 섹션 "직위": "대표", "이사"(부분 가림)…

**이벤트** — "조직도 보기" 클릭 시 트리형 조직도 뷰 전환(추정). 항목 선택 시 우측 "선택없음"이 선택 리스트로 갱신. 다중선택형(발령 대상 복수 가능).

**왜** — 발령은 개인뿐 아니라 조직단위·직위단위 일괄 적용이 흔함(예: "개발팀 전체 전보", "대표 직위 전원"). 조직/직위/구성원을 한 picker로 묶은 것은 Teamlet의 `RecipientPicker` 재사용 원칙(결재선/공지/발령 4곳 공용)과 동일 패턴. 컬러 조직칩은 조직 식별성 향상 UX.

- "기본 정보 변경" [완료] · "강영웅 · 2025. 10. 10 (금) 오후 6:30"

**이벤트** — 연도 셀렉터 → 연도 변경(174949·175002). 행 ▼ → 적립/사용 상세 펼침. "조정" 열 ✎ → 관리자가 수동 가감(잔여 보정). ⓘ → 항목 설명 툴팁.

**왜** — **월차형 적립(매월 +1일)**은 근로기준법 제60조 ② "입사 1년 미만자 1개월 개근 시 1일" 규정의 정확한 구현. 입사월(5월)은 미적립, 6월부터 +1일/월 → 잔여 누적(1·2·3·4일). 자동부여/소멸/사용/조정 4축은 연차 회계의 표준(소멸=촉진 후 미사용 소멸, 조정=오류·특별부여 수동보정). Teamlet `LeaveLedger`(거래원장) + 자동부여 워커 + `LeaveAdjustment`(권한자만, audit) 설계와 직결. 시점 잔여 = 누적합 쿼리.

## [175041] 워크플로우 — 내 문서함 (진행중, 빈 상태)

**화면 식별** — 도메인: 워크플로우 > **내 문서함**. URL: `flex.team/workflow/archive/my/?tab=in-progress`. 상단 탭 "내 문서함 | 회사 문서함"(내 문서함 활성). 서브탭 "진행중 | 완료 | 중요 | 전체".

**레이아웃·디자인** — 제목 "내 문서함" + "회사 문서함"(우측 회색). 우상단 버튼 "📄 문서 양식 관리"(아웃라인) + "✎ 문서 작성하기"(녹색). 우측 상단 보조: "🔍 · ↕ 정렬 · ▦ 그룹 · ⊙ 보기 ▾". 필터바: "전체 | 내가 작성한 · 작성자 ▾ · 양식 ▾ · 업데이트일 ▾ · + 필터 추가" / 우측 "0건 · 초기화 · 보기 저장". 본문 중앙 빈 상태(문서 아이콘 + 안내 + CTA).

**verbatim**
- 탭: "내 문서함 / 회사 문서함" · 서브탭 "진행중 / 완료 / 중요 / 전체"
- 우상단 버튼: "문서 양식 관리", "문서 작성하기"
- 필터: "전체", "내가 작성한", "작성자 ▾", "양식 ▾", "업데이트일 ▾", "+ 필터 추가"
- 우측: "0건", "초기화", "보기 저장"
- 빈상태 제목: "진행 중인 문서가 없어요."
- 빈상태 설명: "결재가 필요한 문서를 작성해 보세요."
- CTA: "작성하기"

**이벤트** — "문서 작성하기"/"작성하기" → 양식 선택 후 문서 작성·결재 상신. "문서 양식 관리" → 양식 CRUD. 서브탭 전환 → 진행중/완료/중요/전체 필터. "보기 저장" → 필터 프리셋 저장.

**왜** — Flex의 워크플로우는 모든 결재성 문서(휴가/지출/품의/정보변경 등)를 단일 문서함으로 통합. **"내 문서함 vs 회사 문서함"** = 본인 상신/관여 문서 vs 회사 전체 문서(권한 스코프). "진행중/완료/중요" 상태 분류 + 풍부한 필터·보기저장 = 결재 적체 추적 UX. Teamlet 핵심 설계와 일치: 휴가/공지/할일/정보변경 모두 `FormDocument.document_kind` + `ApprovalPolicy.category`로 통합, 양식은 `FormTemplate`. "문서 양식 관리"는 회사별 결재양식 정의(범용성).

## 종합 메모 (Teamlet 반영 포인트)

- **인사 발령 = 시점 트랜잭션**: 발령일 우선 고정 + 발령 대상(개인/조직/직위 RecipientPicker 공용) + 발령 라벨(사용자 정의·정렬) + 권한잠금 메모. Teamlet `Appointment` + 새 `PositionHistory` row.
- **정보 일괄 변경 = BulkOperation 강제**: 카테고리(기본/근무/연차/계약/급여/기타[특이사항·가족·경력학력]) × 대상필터(재직상태·계약유형·계약상태·조직·직무·직책·직위·직급) × 엑셀 템플릿. "관리 권한 범위 밖 제외" = scope 강제. createMany 직접호출 금지.
- **휴가 정책 = LeavePolicy 테이블화**: 연차(월차 자동적립, 근기법 60조②) / 경조사(촌수·이벤트별 정액) / 병가(연차소진 후) / 리프레시(근속조건 🔒) / 법정공가(근소집훈련) — 일수 하드코딩 금지.
- **연차 회계 4축**(자동부여/소멸/사용/조정) = `LeaveLedger` 원장 + 시점 잔여 누적쿼리 + 조정은 권한자·audit.
- **연차 촉진/사용계획**(근기법 61조) = `LeavePromotion`+`LeaveUsagePlan`, 빈상태 안내까지 동일.
- **워크플로우 통합 문서함** = `FormDocument`+`FormTemplate`+`ApprovalPolicy`, 내/회사 문서함 권한 스코프 + 상태탭 + 필터/보기저장.
