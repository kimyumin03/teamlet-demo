## 공통 레이아웃·디자인 참고 (전 화면 공통)

- **상단바(고정)**: 좌측에 흰 배경 `✕ 나가기` 버튼(아웃라인, 라운드). 우측 상단에 녹색 채움 버튼 `✓ 입력 완료 ▾`(우측 캐럿 = 분할/드롭다운 버튼 형태). 녹색은 flex 시그니처 컬러 — **Teamlet 에서는 Slate 900 / Cool Blue 600 으로 치환할 것(그라데이션·녹색 금지).**
- **본문**: 회색 배경 위에 **중앙 정렬 단일 컬럼**(폭 ~620px). 각 섹션은 흰색 라운드 카드. 카드 상단 좌측에 토글 스위치 + 섹션 제목, 우측 끝에 작은 `선택` 텍스트 버튼.
- **필드 패턴**: 라벨 위, 입력창 아래. 필수 라벨에 빨강 `*`. 입력창은 연회색 보더 라운드. 검색형 셀렉트는 우측에 돋보기(🔍) 아이콘, 단순 셀렉트는 우측에 상하 캐럿(⇅). 도움말이 있는 라벨은 라벨 옆 `ⓘ`(회색 동그라미 물음표).
- **검증 메시지**: 입력창 바로 아래 빨강 텍스트(`입력해 주세요.` 등).
- **드롭다운**: 입력창 바로 아래로 흰 패널 펼침, 현재 선택값에 좌측 체크(✓), 호버 행 연회색 하이라이트.
- **빈 상태(설정 모달)**: 중앙 정렬 아이콘 + 안내문 2줄 + 아웃라인 `만들기` 버튼.
- URL 은 24장 모두 `flex.team/people/user-invite`. 브라우저 탭 2개(좌: `flex`, 우: `kimyumin03/Teamlet: axhub`).

### rationale — 이 페이지가 존재하는 이유
- HR SaaS 의 **구성원(직원) 마스터 데이터 최초 등록** 진입점. 초대 메일 발송형이 아니라 **관리자가 직접 신원·인사·근로계약·임금계약을 한 번에 입력**하는 온보딩 폼.
- 4개 섹션을 토글로 나눈 이유(추정): 초대 시점엔 기본정보만 필수이고, 인사발령/계약 정보는 입사 확정 후 채워도 되므로 **단계적·선택적 입력**을 허용. 한국 HR 실무상 입사 전 후보자엔 기본정보만, 정식 채용 후 인사·계약 정보를 붙이는 흐름과 일치.
- Teamlet 매핑: 기본정보→`User`+`Employee` 생성, 인사정보→`PositionHistory`/`Appointment`, 근로계약→근로계약 엔티티, 임금계약→급여계약 엔티티. **모두 시점기반 이력 row 로 생성(UPDATE 금지).**

## [172956] 기본정보 — 근무유형 드롭다운 열림

**verbatim 문구**

- `이름 *` / placeholder `이름 입력` / 검증 `입력해 주세요.`
- `회사 이메일 *` / placeholder `회사 이메일 계정 입력` / 검증 `이메일 형식이 올바르지 않습니다.`
  - 보조설명: `회사 업무에 사용할 이메일 주소를 입력하세요. flex 로그인에 사용됩니다.`
- `개인 이메일` / placeholder `개인 이메일 입력`
  - 보조설명: `입사 전이나 휴직, 퇴직 등으로 인하여 회사 이메일에 접근할 수 없을 때 사용할 보조 이메일을 추가해 주세요.`
- `입사일 *` / placeholder `입사일 입력` / 검증 `입력해 주세요.`
- `그룹 입사일` / placeholder `입사일 입력` / 체크박스 `입사일과 동일`(기본 체크 ON)
- `근무유형 *` / 현재값 `[고정 근무유형] 샘플 근무유형` / 우측 링크버튼 `근무유형 설정`
- 드롭다운 옵션(2):
  - ✓ `[고정 근무유형] 샘플 근무유형`
  - `[고정 근무유형] 기본 근무 유형`

**이벤트 동작**: 근무유형 입력창 클릭→하단 드롭다운 펼침. `근무유형 설정` 링크는 근무유형 관리 화면으로 이동 추정.

**rationale**
- `회사 이메일`이 로그인 ID 역할(SSO 계정) → 멀티테넌시에서 회사별 신분의 식별자.
- `개인 이메일`: 휴직/퇴직 시 회사 메일 접근 불가에 대비한 백업 채널 — 한국 실무상 퇴직자 증명서/연말정산 안내 발송에 필요.
- `입사일` vs `그룹 입사일`: 그룹사(관계사 전입)일 경우 **실제 그룹 최초 입사일**을 별도 보관(연차·근속·퇴직금 산정 기준이 다를 수 있음 → 근로기준법상 계속근로연수). 기본은 `입사일과 동일`.
- `근무유형`: 소정근로시간/유연근무/시차출퇴근 등 근태 정책 묶음. `[고정 근무유형]` 접두 배지로 정책 종류 구분.

## 종합 메모 (Teamlet 구현 시사점)

1. **단일 긴 폼 + 토글 섹션** 구조: 기본정보(필수) / 인사·근로계약·임금계약(선택 토글). 점진적 입력 UX.
