## [172902] 구성원 초대 — "기본정보 입력" 풀스크린 폼 (고해상도, 명확)

  - 제목(2줄): **"초대할 구성원의"** / **"정보를 입력해 주세요."**
  - 부제: **"이름, 이메일, 입사일만 입력하면 바로 초대할 수 있습니다."**

  1. **"이름 *"** — 입력박스 placeholder **"이름 입력"**
  2. **"회사 이메일 *"** — placeholder **"회사 이메일 계정 입력"** / 하단 도움말 **"회사 업무에 사용할 이메일 주소를 입력하세요. flex 로그인에 사용돼요."**
  3. **"개인 이메일"** — placeholder **"개인 이메일 입력"** / 하단 도움말 **"입사 전이나 휴직, 퇴직 등으로 인하여 회사 이메일에 접근할 수 없을 때 사용할 보조 이메일을 추가해 주세요."**
  4. **"입사일 *"** — placeholder **"입사일 입력"** (드롭다운 캐럿)
  5. **"그룹 입사일"** — placeholder **"입사일 입력"** + 우측 체크박스 **"✓ 입사일과 동일"**

  - **최소입력(이름·회사이메일·입사일)으로 즉시 초대** = 온보딩 마찰 최소화. 나머지는 본인/추후 입력.

## 종합 특이사항 / Teamlet 적용 메모

- **뷰 토글(테이블 ↔ 카드)** + **표시 컬럼/정렬/그룹 커스터마이즈**가 구성원 페이지의 핵심 UX. Teamlet 구성원 목록도 "사용자 정의 보기(저장 가능)"를 권장.
- **표시 필드 거버넌스 패널**(우측 "조직 정보 설정")이 매우 김 = 한국 인사기록카드 필드 풀세트가 여기 다 있음 → 인사정보 스키마 설계 체크리스트로 활용.
- **직위/직책/직무/직급 4분리**, **입사일 vs 그룹 입사일 분리**, **회사 vs 개인 이메일 분리** = 한국형 SaaS 필수 모델링. Teamlet 스키마에 반영 확인 필요.
- **초대 라이프사이클**(초대 현황 탭 + 재발송/수정/취소)은 멀티테넌시 가입 플로우의 일부 — `UserCompanyMembership` 초대 상태머신으로 구현.
- **일정 위젯의 "확정 일정만 보기"**는 워크플로우(미확정/확정) 상태가 캘린더에 투영됨을 시사 → 휴가 신청·결재 상태를 일정에 색/배지로 구분.
- 컬러: 전반적으로 Flex 의 **초록 CTA + 청록 강조 + 핑크 에러**. CLAUDE.md 원칙 5에 따라 전부 Cool Slate/Cool Blue/디자인 토큰으로 치환 필수(직접 카피 금지).
