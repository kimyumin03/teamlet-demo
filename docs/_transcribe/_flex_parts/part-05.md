## [174017] 여러 명 추가하기 — 엑셀형 그리드 입력 (1/2)

**1. 화면 식별** — 구성원 > 「여러 명 추가하기」전체화면(풀스크린 오버레이). URL: `flex.team/people?user-statuses=in-apprenticeship&user-statuses=in-employ&user-statuses=resignation&user-statuses=resignation-scheduled&user-statuses=leave-of-abse…` (재직 상태 멀티 쿼리 파라미터로 구성원 목록 필터 컨텍스트 위에 모달 진입). 상단 좌측 `×` 닫기 + 제목 **여러 명 추가하기**.

**2. 레이아웃·디자인** — 2분할: (좌, 대부분) 스프레드시트형 입력 그리드 / (우, ~420px) 「입력 정보 설정」패널. 그리드 헤더 컬럼: ☐체크박스 · **입력 상태** · **재직 상태** · **이름**˙(빨강 별=필수) · **이메일**˙ · **입사일**˙. 빈 셀 placeholder는 회색 「검색」/「날짜…」. 행은 빈 행 다수(스크롤). 하단 고정 바: **1명 선택  재직 0 · 입사 예정 0 · 휴직 0 · 퇴직 0**.

**3. 문구(verbatim)** — 제목「여러 명 추가하기」. 우패널 제목「입력 정보 설정」, 부제「추가할 구성원 정보를 선택하세요.」, 검색 placeholder「정보 검색」. 섹션①「사용중인 정보」+우측 링크「모두 미사용」. 섹션②「미사용 정보」+우측 링크「모두 사용」. 하단「1명 선택」「재직 0 · 입사 예정 0 · 휴직 0 · 퇴직 0」.

**4. 선택창/패널 구성** — 우 패널「사용중인 정보」(드래그 핸들⠿ + 행 + 눈👁 토글): **이름**˙ / **이메일**˙ / **입사일**˙ (별표=필수, 끌 수 없음). 「미사용 정보」(눈-끔 아이콘): 그룹 입사일 / 입사 유형(ⓘ) / 근로 계약 정보(ⓘ) / 조직·직책·조직장(ⓘ) / 겸임 조직·직책·조직장 / 직무 / 직군 / 직위 …(더 있음). 각 항목 눈 토글로 사용/미사용 전환 → 좌측 그리드 컬럼 즉시 추가/제거.

**5. 이벤트 동작** — 미사용 정보의 👁 클릭 → 사용중으로 이동 + 그리드에 해당 컬럼 출현(이미지 174026에서 확인). 「모두 사용/모두 미사용」 = 일괄 토글. ⓘ 호버 → 항목 설명 툴팁. ⠿ 드래그 → 컬럼 순서 변경. `×` → 모달 종료(입력값 있으면 추정: 확인 다이얼로그).

**6. 왜(rationale)** — 한국 기업은 신규 입사자를 **분기/공채 단위로 대량 등록**하므로 엑셀형 그리드가 필수. 필수 3종(이름·이메일·입사일)만 강제하고 나머지는 옵션 토글 → 회사마다 관리 필드 편차가 커서(범용성 원칙) 유연성 제공. *추정:* 이메일=계정 초대 키, 입사일=연차 자동부여·근속 기산점이라 필수 강제. Teamlet 대응: `BulkOperation`+`BulkOperationRow` 경유(Anti-pattern #11 — `createMany` 직접 호출 금지), 컬럼 토글은 회사별 `사용 인사정보 카탈로그` 설정과 연동.

**1. 화면 식별** — 동일 화면. 우패널에서 다수 항목을 「사용중」으로 켠 결과.

**3. 문구** — 새 컬럼 헤더「그룹 입사일」「입사 유형」「근로 계약 시작일(적용일)」「근로 계약 종료일」. 빈 셀 placeholder「검색」「날짜…」.

**6. 왜** — 「근로 계약 시작일=적용일」 병기는 **근로기준법상 근로계약 효력 발생일**과 시스템 적용일을 일치시키기 위함. 그룹 입사일 = 계열사 그룹 전체 기준 입사일(경력 인정·퇴직금 산정). Teamlet: 이 필드들은 `시점 기반 이력`의 시작점이 되므로 입력값이 곧 첫 `PositionHistory`/`ContractHistory` row의 effective_from.

## [174135] 조직도 (Org Chart)

**3. 문구** — 「기준일 오늘」「필터 추가」「계약월급 총합 -」「구성원 유지율 -」「트렌드」「조직뷰」. 카드 인원 배지 숫자.

**5. 동작** — 카드 클릭 → 우측 조직 상세 패널(이미지 174216). 「⋯」(카드) → 카드 메뉴. 「4 ▲」→ 하위 접기/펼치기. 기준일 ▾ → 변경일 목록(174149). 필터 추가 → 필드 메뉴(174158). 트렌드 버튼 → 카드 지표 토글(174207). 우상단 「⋯」 → 조직도 다운로드(174316).

**6. 왜** — **「기준일」은 시점 기반 이력의 핵심 UX** — 과거 특정일의 조직 구성을 그대로 재현(인사발령 이력 추적·감사). Teamlet 핵심 설계와 정확히 일치(`getEmployeePositionAt`). 카드 통계(계약월급 총합·유지율)는 조직장 의사결정 지원. 도트 캔버스=대규모 조직 팬/줌. ⚠️ 다만 초록 배지·통계칩 강조색은 Slate/Cool Blue로 변주.

1. **시점 기반 이력이 화면 전반의 일관 컨셉** — 조직도「기준일」, 조직도 설정「적용일」, 변경 내역 스냅샷, 인사 발령「작성일 vs 발령일」, 발령 전/후 비교. Teamlet 핵심 설계(`Appointment`+이력 row)와 정확히 부합 → 그대로 채택하되 UI는 변주.
2. **일괄 처리 3종**: 엑셀 일괄 입사 / 정보 일괄 변경 / (인사) 일괄 발령. 모두 `BulkOperation`+`BulkOperationRow` 경유 강제.
3. **분류 6축**(조직·직무·직군·직책·직위·직급)이 추가 드롭다운·필터·템플릿 컬럼에 반복 등장 → 마스터 데이터로 정규화 + 필터 소스 재사용.
4. ⚠️ **금지 차용**: 초록→청록 그라데이션 CTA(여러 곳), 초록 강조 배지/체크. → Slate 900 단색 + Cool Blue 액센트로 전부 변주.
5. **감사·민감정보**: 발령 메타(작성자/발령일/변경정보/메모) = audit 4요소. 주민번호·계좌·임금 등은 권한·암호화 대상.
