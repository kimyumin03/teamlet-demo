> **왜(rationale):** GNB 1차 메뉴가 곧 HR SaaS 도메인 지도. 근태(근무/휴가/근태관리)·인사(구성원)·워크플로우(전자결재)·채용 파이프라인(후보자평가/채용)·분석(인사이트)·문서(증명서 발급)·설정을 한 레일에 둠. "근무중/자동 기록 중" pill은 출퇴근 자동기록(근태) 상태를 GNB 최상단에 상시 노출 → 근로시간 기록 누락 방지(근로기준법상 근로시간 산정·연장수당 근거). Teamlet GNB 설계 시 동일 1차 카테고리 채택 가능(컬러는 Cool Slate).

## [175543] 워크플로우 — 양식(폼) 빌더 편집기 (신규 양식)

1. **화면 식별** — 도메인: 워크플로우(전자결재) > 양식 관리. URL: `flex.team/workflow/.../sheet/...?tab=all` 류. "양식 만들기/편집" 풀스크린 모달(중앙 카드 + 우측 결재선 패널). 좌측 상단에 보라색 pill 배지(`임시저장` 추정).
2. **레이아웃·디자인** — 중앙 흰 카드(폼 본문) + 우측 패널(`양식 분류` / 결재선 구성). 카드 우상단에 아이콘 3개: 패널 토글(사이드패널), 전체화면(↗↙), 닫기(×). 상단 우측에 `1` 카운터(페이지/필드 수 추정). 하단 고정 CTA = 그라데이션 초록 버튼 `양식 저장하기`(=flex 시그니처 초록, Teamlet에서는 금지 → 단색 Slate/Blue로 변주).
3. **verbatim 문구**
   - 제목 입력 placeholder: `"양식 이름을 입력해 주세요."`
   - 부제 placeholder: `"…에 대한 설명을 입력해두면 작성자가 확인할 수 있어요."`
   - 필드 추가 트리거: `"+ 필드 추가하기"` (체크 아이콘 + 텍스트)
   - 리치텍스트 본문 placeholder: `"내용을 입력하세요"`
   - 하단 CTA: `"양식 저장하기"`
   - 우측 패널 헤더: `"양식 분류"` (우측 `+`)
   - 우측 패널 상단 토글/버튼: `"요청자별 승인"`, `"변경 허용"`(파란 활성), `"📥 템플릿"`
   - 결재 단계: `"참조"` / `"1 단계 승인"` / `"2 단계 승인"` (각 `+`), 2단계에 `자동 진행` 배지 + 🗑(삭제)
   - 각 단계 placeholder: `"추가하기"` + `"참조자를 추가해 주세요."` / `"승인자를 추가해 주세요."`
   - 우측 패널 하단: `"+ 승인 단계 추가하기"`
   - 리치텍스트 툴바: B / i / U / S(취소선) / `14px`(글자크기 드롭다운) / 글머리기호 목록 / 번호 목록 / 정렬(좌·중·우·양쪽) / 이미지 / 표 / 링크 / 실행취소 / 다시실행
4. **선택창/모달 구성** — 우측 결재선은 단계별 카드. `참조`/`1단계 승인`/`2단계 승인` 각각에 결재자 추가(`+`). `자동 진행` 배지 = 해당 단계 자동 승인/스킵 옵션. `요청자별 승인` = 요청자에 따라 결재선 분기. `변경 허용` = 작성자가 결재선 수정 가능 여부.
5. **이벤트** — 제목/본문 인라인 편집. `+필드 추가하기` 클릭 → 필드 타입 드롭다운(이미지 2). 단계 `+` → 결재자(RecipientPicker) 추가. 🗑 → 단계 삭제. 저장 → 양식 템플릿 확정.
6. **왜(rationale):** 전자결재 양식 빌더 = 워크플로우 코어. 회사마다 결재선·필드가 달라 **노코드 폼 디자이너**가 필수. `참조`(열람만, 승인권 없음) vs `N단계 승인`(순차 결재) 구분은 한국 전자결재 관행(상신→1차 결재→2차 결재→참조 통보). `요청자별 승인`은 부서/직급에 따라 결재선 자동 분기(예: 팀원→팀장→본부장 vs 임원→대표). `자동 진행`은 결재 지연 방지(부재·기한초과 시 자동 승인). Teamlet은 `FormDocument.document_kind` + `ApprovalPolicy.category`로 통합, 결재자 선택은 `RecipientPicker` 재사용(anti-pattern #10).

## [175605] 양식 빌더 — 필드 타입 추가 드롭다운 (전체 옵션)

1. **화면 식별** — 이미지 1과 동일 편집기에서 `+필드 추가하기` 클릭 → 좌측에 필드 타입 선택 드롭다운 펼쳐짐.
2. **레이아웃·디자인** — 세로 리스트, 각 항목 = 라인 아이콘 + 라벨. 섹션 구분 헤더(옅은 회색 소제목)로 그룹화. 호버 시 회색 하이라이트(예: `다중 선택` 하이라이트됨).
3. **verbatim — 필드 타입 전체 목록(위→아래):**
   - (기본 입력) `글자` / `숫자` / `금액 (원)` / `금액 (달러)` / `금액 (엔)` / `날짜` / `선택` / `다중 선택` / `참조 문서`
   - 섹션 헤더 `구성원 정보 연동`: `이름`(Aa) / `닉네임` / `영문 이름` / `이메일` / `전화번호` / `생년월일`
   - 섹션 헤더 `인사 정보 연동`: `사번`(#) / `조직` / `직책` / `직무` / `직위`
4. **선택창 구성** — 3그룹: (1) 자유 입력 필드, (2) **구성원 정보 연동**(프로필 자동 채움), (3) **인사 정보 연동**(인사이력 자동 채움). 아이콘: 글자=Tt, 숫자=1, 금액=₩/$/¥, 날짜=캘린더, 선택=라디오, 다중선택=리스트, 참조문서=링크, 사번=#, 조직=조직도, 직무=눈금자 등.
5. **이벤트** — 항목 클릭 → 본문에 해당 필드 삽입. `참조 문서` = 다른 결재 문서 연결.
6. **왜(rationale):** **연동 필드**가 핵심 차별점. `구성원/인사 정보 연동` 필드는 작성자가 직접 입력하지 않고 **인사 마스터에서 자동 fetch** → 오타·구버전 정보 방지, 단일 진실원천(SSOT). 금액을 원/달러/엔 3종으로 분리한 건 외화 경비·해외법인 정산 대응(범용성). `참조 문서`는 결재 간 관계(예: 출장신청→출장정산) 추적. Teamlet은 인사 연동 필드를 **시점 쿼리**(`getEmployeePositionAt`)로 결재 상신 시점의 조직/직책을 스냅샷해야 함(나중에 조직 바뀌어도 문서 무결성 유지).

## [175634] 양식 빌더 — 풋터 필드 "사용 여부" 드롭다운 (3-state)

1. **화면 식별** — 편집기 카드 하단 풋터의 부가 필드(예: 첨부파일/댓글 등) 토글을 클릭 → 사용 여부 드롭다운.
2. **레이아웃** — 작은 컨텍스트 메뉴, 흰 카드 + 라운드. 현재 선택 항목에 우측 초록 ✓.
3. **verbatim — 옵션(3-state):**
   - `"사용 안 함"` (현재 ✓ 선택)
   - `"선택 사용"`
   - `"필수 사용"`
4. **선택창 구성** — `사용 안 함`(필드 비활성) / `선택 사용`(작성자 선택 입력, optional) / `필수 사용`(작성 시 필수, required). `사용 안 함`과 나머지 사이 divider.
6. **왜:** 양식 항목의 **노출/필수 제어**. 회사·양식별로 첨부·사유 등 필드 필수 여부가 달라 3단계 토글 제공. `필수 사용`은 결재 상신 차단 검증(미입력 시 제출 불가) → 데이터 품질·감사 대응. Teamlet은 양식 스키마의 `required: boolean | 'optional' | 'off'`로 모델링.

## [175642] 양식 빌더 — 풋터 필드 "사용 여부" 드롭다운 (2-state)

3. **verbatim — 옵션(2-state):**
   - `"사용 안 함"`
   - `"사용"`
4. **선택창 구성** — 단순 on/off(필수 단계 없는 필드, 예: 댓글 허용·공개 여부 등).
6. **왜:** 일부 부가 기능은 필수개념이 없어 on/off만 필요 → 3-state와 2-state를 필드 성격에 따라 분기. UX 단순화 의도.

## [175700] 양식 빌더 — OS 파일 선택 대화상자 (파일 업로드 이벤트)

## [175714] 양식 빌더 — 신규 양식 편집(임시저장 상태, 워크플로우 컨텍스트)
