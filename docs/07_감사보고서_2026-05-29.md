## 1. 🔴 CRITICAL — 즉시 조치 (배포·보안·데이터 무결성)

### C1. [보안/H] 경력·학력·가족 12개 함수 전역 IDOR — 멀티테넌트 붕괴
- **위치**: `packages/modules/src/employee/career.ts` 전체 (라인 32,98,124,160,225,251,285,348,373 등)
- **내용**: `assertPermission`은 **actor 회사 기준 권한만** 확인하고, 대상 `employeeId`/`careerHistoryId`/`familyMemberId`가 actor 회사 소속인지 검증하지 않음. ctx에 targetEmployeeId도 미전달 → scope도 안 걸림.
- **영향**: `member.directory.manage` 권한을 가진 A사 관리자가 임의 id로 **B사 구성원의 가족·학력 등 민감 개인정보 조회·수정·삭제 가능**. update/delete는 employeeId 검증조차 없어 id 하나로 전역 접근.
- **AxHub 다회사 배포 환경에서 치명적.** 최우선 수정.

### C2. [배포/H] Docker 컨테이너 기동 실패 확정
- **위치**: `Dockerfile:35,43` — `output:"standalone"` + `next build --turbopack`
- **내용**: Turbopack 프로덕션 빌드는 standalone 출력(`.next/standalone/server.js`)을 생성하지 않음. `CMD ["node","apps/web/server.js"]`가 존재하지 않는 파일을 실행.
- **영향**: 현 Dockerfile로 AxHub 배포 시 **런타임 기동 실패**. `axhub.yaml`은 있으나 무의미.
- 관련: PROGRESS의 "standalone 패키징 실패 — Windows 권한" 메모와 별개의 빌드 도구 충돌 이슈.

### C3. [데이터/H] 연차 소멸·이월 엔진 사실상 1회용
- **위치**: `packages/modules/src/leave/balance.ts:205-208`
- **내용**: 멱등 검사 `findFirst({ where: { employeeId, leaveTypeId, txType:"EXPIRE" } })`에 **`year` 조건 누락**. 2025년 소멸 1회 실행 후 2026년 처리 시 2025 EXPIRE가 검색돼 영구 skip. 이월 GRANT도 동일 → 첫 해 이후 소멸 자체가 막힘.
- **추가 [H]**: 소멸이 `grantedDays`가 아닌 `adjustedDays`를 decrement (balance.ts:251-254) → adjustedDays가 음수로 오염, UI는 소멸을 "관리자 조정 -X"로 오표기.

### C4. [데이터/운영/H] 가입코드 신청 알림 단절 + 잘못된 Prisma 필터
- **위치**: `packages/modules/src/tenancy/index.ts:238-239`
- **내용**:
  - 알림 대상을 `role: { name: "ADMIN" }`로 조회하나, 부트스트랩은 `type:"SYSTEM_SUPER_ADMIN"`로 역할 생성 → 이름 불일치 시 **회사 관리자에게 알림 안 감**.
  - 같은 쿼리 `employee: { companyId, status: "ACTIVE" }` — Employee에 `status` 필드 없음(실제 `employmentStatus`) → **잘못된 필터, 런타임 에러 또는 0건 매칭**.
- **영향**: 가입코드로 가입 신청해도 관리자가 인지 못 함 → PENDING 적체. (사용자가 처음 지적한 "승인 흐름" 문제의 실제 코드 근거)

### C5. [기능/H] Worker BullMQ 빈 부트스트랩
- **위치**: `apps/worker/src/index.ts:30-34`
- **내용**: Redis ping + Queue 핸들 1개만, **Worker 프로세서 0개**. 연차 자동부여·소멸·비동기 알림 어느 것도 실행 안 됨. 자동 스케줄링 전무(모두 관리자 수동 트리거).

### C6. [기능/H] 증명서 인쇄 서버컴포넌트 렌더 버그
- **위치**: `apps/web/src/app/(app)/documents/certificates/[id]/page.tsx:28`
- **내용**: 서버 컴포넌트(async, `await auth()`, no `"use client"`)에서 `onClick={() => window.print()}`. Next.js가 이벤트 핸들러 전달 차단 → **인쇄 페이지 렌더 실패**. PDF 생성도 없음.

### C7. [기능/H] 결재 정책 자동 배정 미연결 (껍데기)
- **위치**: `packages/modules/src/workflow/approval-policy.ts` 전체 + `document.ts:97`
- **내용**: UI(`approval-policies/page.tsx:58`)는 "기안 시 자동으로 결재선이 배정돼요"라고 명시하나, `createDocument`는 ApprovalPolicy를 **조회조차 안 하고** UI가 넘긴 `approverIds`만 사용. 정책 저장은 되나 소비처 0.

## 8. "100% → 120%" 로드맵

> 100% = 명세(transcription) 완전 충족. 120% = 명세를 넘어서는 차별화(flex-analysis §6 옵션).
> **단, 0순위(보안·배포·정합성, §1·§2)를 끝내기 전엔 기능 확장 금지** — 깨진 토대 위에 쌓으면 안 됨.

### 100% 달성 (명세 충족) — 권장 순서
1. **[토대] §1·§2 CRITICAL 9건 + §2 HIGH 9건 전부 해소** (IDOR·Docker·소멸엔진·알림단절·결재정책·보안강제)
2. **근태 모듈 신설** (7-A) — 출퇴근/근무시간 → 홈·프로필·구성원 빈칸 해소
3. **연차 사용 촉진 4-칸반** (7-A) — 소멸엔진과 연결, 근로기준법 충족
4. **워크플로우 인라인 결재 + 결재선 spine + 신청자 컨텍스트** (7-B)
5. **설정 3종 실구현**: 보안(세션관리)/알림(채널 영속화)/회사정보(로고 업로드) (7-C)
6. **파일 업로드(MinIO 연동)** — 로고·프로필·문서·이력서·증명서PDF (docker-compose에 MinIO 이미 있음)
7. **포스트 타입 다양화 + 댓글/읽음추적/반응 영속** (7-B)
8. **온보딩 체크리스트 + 발령 통합 타임라인** (7-A/B)
9. **문서함 자동발송 규칙(IF→THEN)** (7-C)

### 120% 차별화 (flex-analysis §6) — 토대+100% 이후
- **Command palette 중심 네비** (Linear 스타일) — ⌘K 확장: 액션 실행까지
- **AI 어시스턴트 패널** — 휴가 자동 분석, 결재 패턴 추천 (Claude API 연동)
- **다크모드 + 5 accent 테마 스위처** 완성
- **데이터 그리드 + 갤러리 뷰 병행**
- **AxHub 구성원 sync** (sync_locked_fields 준수) — 양방향 동기화

### 품질 게이트 (전 단계 공통)
- **테스트 인프라 구축(vitest)** — 정합성 로직(휴가 잔여계산·소멸·결재 트랜잭션)부터 회귀 테스트. 현재 0건.
- 각 기능 **런타임 검증** 후에만 PROGRESS "완료" 표기 (과대표기 금지 원칙).
