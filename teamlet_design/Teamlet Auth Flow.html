설계 노트

  • 비밀번호 없음 (passwordless) — 브리프 명시. 이메일 매직링크 + 임시 비밀번호 1회 발급. UX 마찰 ↓, 보안 ↑
  • 2FA TOTP 6자리 — 입력 칸 시각적 분리 + 입력 위치 명확. 24초 카운트다운으로 재발급 시점 안내
  • 회사 가입 3옵션 — 등록 / 코드 / 초대 대기. 가장 일반적인 "등록"이 default selected (1번 → 5번 흐름이 sales-led 진입로)
  • 승인 대기 = 활동형 상태 — 5초 폴링, 타임라인으로 진행 단계 가시화, 평균 검토 시간 명시 → 불안 ↓
  • 반려 = 액션 두 개 — "다시 선택" (회사 가입 페이지로) / "재신청" (등록 신청 폼으로 사유 반영). 막다른 길 X
  • Required indicator — * + destructive 컬러. 시각적으로 즉시 인지
