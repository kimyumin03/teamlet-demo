설계 근거 — 무엇을 다르게 했는가

레퍼런스 대비 개선 포인트 · 다음 단계 디자인 의사결정의 베이스라인

1. 정보 위계

  • "오늘 회사가 돌아가는 감각"을 첫 뷰에 — 상단 4개 KPI 카드 + 우측 팀 현황으로 빈 상태에서도 의미 있는 화면.
  • 제목 영역에 출근 38 / 휴가 4 / 재택 6 인라인 메타데이터 — 위젯에 의존하지 않는 즉시 확인.
  • 탭 옆 카운터(소식 2, 할 일 7)로 행동 우선순위가 한눈에 보임.

2. 탭 구조

  • 홈 피드: 공지·인정·이벤트(생일·입사)를 시간순으로 섞은 단일 스트림.
  • 소식: 공식 공지/회사 발표만 필터링. 읽음률 노출로 운영자가 도달률 확인.
  • 할 일: 결재·평가·온보딩을 마감순 단일 큐로 통합. flex의 분산된 진입점 문제를 해결.

3. 비주얼 시스템

  • 1색(잉크) 기반 · 상태 컬러는 urgent / soon / normal + 휴가/재택/지각만 색 사용 → 색 인플레이션 방지.
  • 모든 카드 radius 10, 행 radius 9, 컨트롤 radius 7 — 위계가 형태로 표현됨.
  • 숫자·시간·메타데이터는 모노스페이스로 통일 — 표 데이터 정렬과 시각적 신뢰감 동시 확보.

4. 우측 레일

  • 4개 위젯 고정 순서: 팀 현황 → 캘린더 → 자리 비움 → 축하 대상.
  • 캘린더는 "보기 전용" — 일정 생성은 메인 흐름에서. 정보성으로 격하해 인지 부하 감소.
  • 자리 비움 5명 노출 후 "전체 →" 링크. 우측 레일은 요약, 본문은 작업 역할 분리.

5. 사이드바

  • 240px 고정 · 활성 항목은 bg-secondary + ink fill 아이콘.
  • 섹션 3개: 메인 / Workspace / Admin — 권한별 노출 분리 명시.
  • 근무 상태 토글(상단)과 프로필(하단)이 사이드바 양 끝을 잡아주는 앵커.

6. 오픈 이슈

  • 모바일 반응형: 사이드바 → 햄버거, 우측 레일 → 하단 탭으로 압축. v2 작업
  • 다크 모드: 토큰만 정의됨 — 그레이스케일이라 전환 비용 낮음.
  • 피드 무한 스크롤 vs. 페이지네이션 결정 필요.
