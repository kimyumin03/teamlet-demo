flex와의 차이 — 구성원 영역

brief의 3탭 구조(기본 정보 / 발령 이력 / 권한)를 그대로 따르되, 정보 위계를 재구성

flex (현재)

  • 여러 명 추가 화면이 24컬럼 가로 스크롤 인라인 테이블
  • 프로필 우측 16개 점프 메뉴 (인사/기본/근로계약/임금계약/급여지급/근무/초과근무보상/휴가/쉬는 날/휴직 이력/수상/징계/경력/학력/특이사항/가족)
  • 프로필 5탭 정보/성장/교육/문서·증명서/인사노트
  • "입력하기"가 모든 빈 필드에 반복 — 시각적 노이즈
  • 발령 이력이 별도 페이지로 분리

Teamlet (이번)

  • 리스트 8컬럼 + 컬럼 토글 · 가로 스크롤 0
  • 본문 acc 7개 인사 / 기본 / 근로계약 / 임금·급여 / 근무·휴가 / 학력·경력·자격 / 가족·기타
  • 프로필 3탭 (brief 준수) 기본 정보 / 발령 이력 / 권한
  • 빈 값은 "미입력" 한 가지로 통일 + na 컬러 — 액션은 acc 펼친 후 한 번에
  • 발령 이력은 프로필 안의 탭 · 채용/처우협의/입사/발령이 하나의 타임라인

세부 설계 결정

정보 그룹화 · 빈 상태 · 권한 가시화

1. 리스트 전략

  • 기본 컬럼 8개: 이름 · 사번 · 이메일 · 조직·직책 · 입사일 · 근로유형 · 상태 · 권한
  • 나머지 16개는 컬럼 토글로. 사용자별로 본 컬럼 조합은 로컬 저장
  • 일괄 액션은 선택 후 footer bar로 노출 — 모달 stack 없음

2. 리스트 ↔ 조직도

  • 같은 데이터의 두 단면 — URL ?view=org로만 분기, 별도 페이지 X
  • 조직도는 "팀 + 인원수" 카드만 표시. 클릭 시 해당 팀 리스트로 drill
  • flex는 조직도가 미완성 — Teamlet은 v1부터 1-depth 카드로 시작, 2-depth는 옵션

3. 프로필 hero

  • 상단에 5개 quick chips: 연차 · 근무 · 결재 · 온보딩 · 2FA — 가장 자주 확인
  • flex의 우측 사이드(profile + jump menu)를 hero로 위로 끌어올림
  • 액션 4개 (메시지/조직 이동/발령/정보 변경)만 노출. 그 외는 ⋯ 더보기

4. acc 그룹화

  • 16개 jump → 7개 의미 그룹: 인사/기본/근로계약/임금급여/근무휴가/학력경력자격/가족기타
  • 첫 3개 (인사·기본·근로계약)는 기본 펼침 — 90% 케이스 커버
  • 각 acc에 요약 sub-text (예: "학력 1 · 경력 2 · 자격증 0") 펼치기 전 의사결정 가능

5. 발령 이력

  • 채용 지원부터 입사·발령까지 하나의 타임라인으로 연결
  • 각 이벤트에 delta box (조직/직무/근로유형의 before → after)
  • flex는 발령 이력에 채용 단계 미포함 — Teamlet은 한 사람의 전체 경로 가시화

6. 권한 가시화

  • flex는 "권한 그룹"만 보임 → 실제 무슨 권한인지 모름
  • Teamlet은 그룹 + 실제 권한 표 2단으로 (읽기/쓰기/승인 × 범위)
  • 그룹은 add/remove, 실제 권한은 자동 계산 — 권한 인지 비용 ↓
